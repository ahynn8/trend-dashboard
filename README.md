# 검색 트렌드 대시보드

> 네이버 데이터랩 API 기반 · 마케팅 키워드 트렌드 분석 도구

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://trend-dashboard-tap.streamlit.app)

---

## 프로젝트 소개

가상 캠페인 기획서의 타겟 가설을 실제 검색 데이터로 검증하기 위해 직접 구현한 분석 대시보드입니다.

유료 툴 없이 네이버 데이터랩 API만으로, 키워드가 **언제·왜·누구에게** 반응했는지를 통계적으로 분석하고 마케팅 액션까지 연결하는 것을 목표로 만들었습니다.

```
"시장에서 어떤 키워드가 왜 올랐는지 파악"
→ KPI 시뮬레이터로 연결해 목표 수치 설계
```

---

## 주요 기능

### 트렌드 분석
- 키워드별 검색량 추이 시각화
- z-score 기반 통계적 이상치 감지 (단순 상승률이 아닌 노이즈 제거 후 급등 탐지)
- 트렌드 유형 자동 분류 (단기 이슈형 / 지속성 상승형 / 반복 패턴형 / 안정형)

### 타겟 분석
- PC vs 모바일 검색 비중 비교
- 성별 비교
- 연령대별 검색 분포

### 이벤트 분석
- 급등 시점 자동 감지 + 당시 뉴스·블로그 딥링크 연결
- 피크 원인 메모 저장 기능
- 마케터 액션 제안 자동 출력

## 실제 분석 결과 (캠페인 기획서 연결)

| 인사이트 | 수치 | 전략 적용 |
|---|---|---|
| 키워드 검색 급등 | z = 11.5 (공휴일 세일 연동 반복 패턴) | 공휴일 전 2주 집중 집행 타이밍 결정 |
| 토너 PC 검색 비중 | 66% | YouTube·Blog 병행 멀티채널 전략 채택 |
| 패션 키워드 모바일 비중 | 100% | TikTok·Instagram 중심 전략, 검색광고 배제 |
